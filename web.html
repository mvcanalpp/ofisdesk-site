Ayarlar

Web paneli canlı Supabase verisiyle çalışır. Tam eşleşme için Dosya Föyü SQL dosyasını Supabase SQL Editor'de çalıştırıp masaüstü uygulamaya aynı tablo desteğini ekleyeceğiz.

Hakkında

OfisDesk, hukuk bürolarının dosya, muhasebe, personel, belge ve talep işlerini tek merkezde yürütmesi için geliştirilmiştir. Web paneli, masaüstü uygulamadaki çalışma düzenini tarayıcıya taşımak için hazırlanmıştır.
